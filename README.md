# homebrew-mcp

Homebrew formulas for my MCP servers.

## Usage

```bash
brew install k3KAW8Pnf7mkmdSMPHz27/mcp/eventkit-mcp-server
```

## Formulas

| Formula | Description |
|---------|-------------|
| [`eventkit-mcp-server`](https://github.com/k3KAW8Pnf7mkmdSMPHz27/EventKitMCP) | MCP server exposing Apple Reminders via EventKit |

Formulas build from source on your machine; no prebuilt binaries are distributed.
Building needs Xcode 26 (Swift 6.2). Version pins are updated automatically when EventKitMCP publishes a release.
